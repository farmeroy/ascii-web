ascii-web

ascii-web provides a web component to easily drop in responsive ascii art on web pages. The ascii generation is written in Rust and runs in WASM. Check out the repo on github

You can install via npm install @ascii-web/client: 

<script type="module">
  import '@ascii-web/client';
</script>
<ascii-img src="my-image.jpg" alt="my-image" ></ascii-img>

Try it out using the following examples:

  • Playground: resize the container, adjust the settings, or try your own image
  • Infinite scroll: a feed of photos from Lorem Picsum
